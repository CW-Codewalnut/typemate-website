# TypeMate website

Landing page for TypeMate, served at [typemate.codewalnut.com](https://typemate.codewalnut.com). The app itself is closed source; its binaries are distributed through the releases of the public [CW-Codewalnut/typemate](https://github.com/CW-Codewalnut/typemate) repo.

Built with Next.js, Tailwind CSS, and Motion. Download links are resolved at runtime from the latest GitHub release of that repo, so nothing here needs updating when a new version ships.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
