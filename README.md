# TypeMate website

Landing page for [TypeMate](https://github.com/CW-Codewalnut/typemate), served at [typemate.codewalnut.com](https://typemate.codewalnut.com).

Built with Next.js, Tailwind CSS, and Motion. Download links are resolved at runtime from the latest GitHub release of the app repo, so nothing here needs updating when a new version ships.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
